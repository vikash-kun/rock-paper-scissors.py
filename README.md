# rock-paper-scissors.py
✊✋✌️ Rock Paper Scissors
A terminal-based Rock Paper Scissors game in Python where you play against the CPU in a best-of-3 match.
How to Play
Run the script and enter a number when prompted:
InputChoice1✊ Rock2✋ Paper3✌️ Scissors
The first to 2 wins takes the match.
Running the Game
bashpython rps.py
Example session:
pick your number : 1
You chose: ✊
CPU chose: ✌️
You win this round!
score -> you: 1 | CPU: 0
Game Rules

Rock ✊ beats Scissors ✌️
Scissors ✌️ beats Paper ✋
Paper ✋ beats Rock ✊
Same choice → Tie (no point awarded)

Requirements

Python 3.x
No external dependencies — uses the built-in random module
